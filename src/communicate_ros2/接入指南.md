# 通信框架 · 接入指南 V1.0

本框架负责「上位机 ↔ 电控主控」的串口通信。**你只做三件事：写一个 `.msg` 声明字段、
在 `interfaces/CMakeLists.txt` 登记、在 `config/ports.yaml` 加一段声明端口。**
串口、组帧、拆帧、订阅、发布全部自动。带代码的参考示例见下。

---

## 加「发送端口」（三步）

以加 **TX P5 底盘动作（float[10]）** 为例（P5~P8 有额外要求，见第五节，先看完再接）：

**① 定义消息** —— 新建 `interfaces/msg/ChassisAction.msg`，按协议顺序写字段，**字段名带单位**：

```
float32 field_1     # 按协议逐个写，共 10 个
float32 field_2
# ...
```

**② 登记消息** —— 在 `interfaces/CMakeLists.txt` 的 `rosidl_generate_interfaces(...)` 里加一行：

```cmake
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/RobotStatus.msg"
  "msg/LocError.msg"
  "msg/LidarPos.msg"
  "msg/ChassisAction.msg"     # ← 新增
)
```

**③ 声明端口** —— 在 `ports.yaml` 的 `tx:` 段加一段：

```yaml
tx:
  # ... 已有端口 ...
  - port: 5                # P5 底盘动作
    topic: robot/chassis_action
    type: robot_interfaces/msg/ChassisAction
```

**完成。** 重新 `colcon build` 后，队友那边只要 `publish` 到 `robot/chassis_action`，框架就自动组帧发串口。

> **字段顺序 = `.msg` 里字段顺序 = 协议 payload 顺序**，别在 yaml 里写字段。
> **别漏第 ② 步**：不登记 CMakeLists，新消息类型不会生成，运行时报「找不到消息类型」。

---

## 加「接收端口」（三步）

主控会按 Port 回数据。以加 **RX P3 武器抓取状态** 为例：

**① 定义消息** —— `interfaces/msg/WeaponGrab.msg`：

```
int32 state     # 注意：RX P3 是 int32，不是 float32
```

**② 登记消息** —— 在 `interfaces/CMakeLists.txt` 的 `rosidl_generate_interfaces(...)` 里加一行：

```cmake
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/RobotStatus.msg"
  "msg/LocError.msg"
  "msg/LidarPos.msg"
  "msg/WeaponGrab.msg"     # ← 新增
)
```

**③ 声明端口** —— 在 `ports.yaml` 的 `rx:` 段加一段：

```yaml
rx:
  # ... 已有端口 ...
  - port: 3                # P3 武器抓取状态
    topic: robot/weapon_grab
    type: robot_interfaces/msg/WeaponGrab
```

**完成。** 框架收到对应帧自动拆包、发布到 `robot/weapon_grab`。

> ⚠️ **int32 还是 float，看协议！** RX P1/P2/P6/P8 是 float32；RX P3/P4/P5/P7 是 **int32**。
> 在 `.msg` 里写对类型就行，引擎会自动按类型打包，用错类型整帧都解析错。

## 完整示例：从零加一个「相机位置」发送端口（TX P10）

下面走一遍**从写文件到真机验证**的完整流程。加的是 TX P10 相机位置（协议 4.8 节：
3 个 float，单位米，主控会 ×1000 存成毫米）。

### 第 1 步：看协议，确定字段

协议 4.8 节：Port 10 payload = `[photo_x_m, photo_y_m, photo_z_m]`，3 × float32，共 12 字节。
字段名带 `_m` 表示单位是米。

### 第 2 步：写消息定义 `interfaces/msg/CameraPos.msg`

```text
# 相机位置（TX P10，3 个 float，12 字节）
# 单位：米。主控会把三个值 ×1000 存为毫米
float32 photo_x_m
float32 photo_y_m
float32 photo_z_m
```

### 第 3 步：在 `interfaces/CMakeLists.txt` 登记

`rosidl_generate_interfaces(...)` 里加一行，否则新类型不会生成：

```cmake
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/RobotStatus.msg"
  "msg/LocError.msg"
  "msg/LidarPos.msg"
  "msg/CameraPos.msg"       # ← 新增
)
```

### 第 4 步：在 `config/ports.yaml` 的 `tx:` 段声明端口

```yaml
tx:
  # ... 已有端口 ...
  - port: 10               # P10 相机位置 [photo_x_m, photo_y_m, photo_z_m]
    topic: robot/camera_pos
    type: robot_interfaces/msg/CameraPos
```

到这里，**框架侧就加完了**：通信节点会自动订阅 `robot/camera_pos`，谁 publish 它就组帧发串口。

### 第 5 步：重新构建

```bash
cd ~/ros2_ws
colcon build --symlink-install --packages-select robot_interfaces communicate_py
source install/setup.bash
```

### 第 6 步：写你自己的节点

新建你算法包里的一个发布节点，例如 `camera_pos_publisher.py`：

```python
import rclpy
from rclpy.node import Node
from robot_interfaces.msg import CameraPos


class CameraPosPublisher(Node):
    def __init__(self):
        super().__init__('camera_pos_publisher')
        self.pub = self.create_publisher(CameraPos, 'robot/camera_pos', 10)
        self.timer = self.create_timer(0.5, self.send)   # 0.5s 发一次

    def send(self):
        msg = CameraPos()
        msg.photo_x_m = 0.3     # 相机 X（米）
        msg.photo_y_m = 0.1
        msg.photo_z_m = 0.25
        self.pub.publish(msg)
        self.get_logger().info(
            f'发送相机位置 ({msg.photo_x_m}, {msg.photo_y_m}, {msg.photo_z_m})')


def main(args=None):
    rclpy.init(args=args)
    node = CameraPosPublisher()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> 串口、组帧、校验、发帧全在通信节点里自动完成。把它注册到你包的 `setup.py`
> `entry_points` 里即可 `ros2 run <你的包> camera_pos_publisher`。

### 第 7 步：运行 + 验证

```bash
# 终端 1：通信节点（框架，负责把话题转成串口帧）
ros2 run communicate_py communicate_node
#   日志里应看到：TX 装配：port=10 <- robot/camera_pos

# 终端 2：你的发布节点
ros2 run <你的包> camera_pos_publisher

# 终端 3：确认话题有数据
ros2 topic echo /robot/camera_pos
```

> **加接收端口（RX）是对称的**：写 `.msg`（注意 int32 还是 float）→ 登记 CMakeLists →
> 在 `rx:` 段声明 → 你的节点 `create_subscription(...)` 订阅。
